# 自媒体助手 1.3.0 · 矩媒整合版

助手负责账号资料、热点选题、AI 文案、素材预览、封面编辑和本机草稿。矩媒作为可选的发布工具，通过本机 HTTP 接口接收视频；不合并双方 Cookie、浏览器配置或账号数据库。

## 开始使用

1. 启动助手，点击右上角「矩媒连接」。填写 matrixmedia.exe 完整路径，端口默认 30088。
2. 点击「打开矩媒」，在矩媒内添加并登录自己的小红书、抖音、B站账号。
3. 回到助手「矩媒连接」测试连接并刷新账号。随后编辑助手账号，选择发布工具和对应矩媒账号。没有绑定的账号可以保存，但不能发布。
4. 在助手准备作品，勾选目标账号，检查平台内容。点击发布后出现本次矩媒确认窗口，核对绑定、文案及矩媒中的创作声明，再勾选确认。
5. 「自动发布」向矩媒发出提交请求；「核对后发布 / 矩媒存草稿」请求保存平台草稿，之后需要在矩媒或平台后台手动提交。矩媒账号自身的默认存草稿设置也可能覆盖提交结果。

## 两种发布工具如何选择

- 抖音、B站原来的助手发布功能继续保留。需要助手封面、合集、B站分区和原权限设置时，选择「助手原发布」。
- 需要矩媒的账号和发布实现时，选择「矩媒发布」。本次只整合三个平台的视频接口，图文以及接口未提供的封面、合集、B站分区会被提前拦截，不会静默忽略。
- 小红书入口已恢复，只通过绑定矩媒账号发布。旧账号和旧 profiles 目录保留，不会迁移登录状态，也不会根据名称猜测绑定关系。
- 矩媒账号的登录、创作声明、分区和其他设置以矩媒中配置为准。助手不会把旧版的“默认尝试个人观点”强加给矩媒。

## 定时与结果

矩媒定时属于电脑上的本机定时，需要保持矩媒和电脑运行。助手输入统一为北京时间，交给矩媒时换算为电脑本地时间；不能把它误认为平台自有定时。助手原发布的定时语义保持原样。

矩媒任务已入队、已保存草稿、本机定时和连接中断均保留为待核对，不推断为公开发布。矩媒确认提交也仍需平台审核。未知结果请先查看矩媒发布记录；矩媒失败任务不走一键重试，须确认未发布后从草稿重新提交并再次确认。

## 数据和验证

账号、草稿、历史记录与原浏览器 profiles 沿用原 data 目录。新增 matrixmedia.json 只保存本机连接设置；账号新增 publish_backend、matrix_partition、matrix_name 字段。读取矩媒账号时只取账号标识，不读取或传递 Cookie。

本次验证使用隔离数据、本机假矩媒 HTTP 服务和本地页面；未登录真实平台或投稿。小红书可能识别第三方工具，本机接口和真实浏览器不构成免风控保证。
